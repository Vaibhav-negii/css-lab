Text, edges and space.

Every element on a web page is a rectangle wearing three layers. CSS fonts decide how the words look, borders draw the edge, and the box model decides how much room the rectangle takes. Learn these three and every layout becomes predictable.

The idea in three parts

Why it matters for web development

A page that "looks broken" is almost always a font choice, a border addition or an unexpected box size. Once you know the three layers, you can read a layout in DevTools and fix it in seconds instead of guessing.

  font-family: "Segoe UI",

The browser walks the list left to right. Ending with sans-serif guarantees that text is never invisible because a font is missing.

Every side, or just one

.card {
  border: 2px solid #4f8cff;
  border-radius: 12px;
}

/* one side only */
.tab {
  border-bottom: 3px solid #ff7a66;
}
Things worth remembering
  1. A border adds to the sizeIn the default box model, a 2px border on each side makes the element 4px wider.
  2. Style is requiredA border with no style stays invisible, even if a width and colour are set.
  3. Radius needs a background or border to showThe corner is only visible where something is drawn.

content-box vs border-box

Switch the toggle above and watch the numbers. With content-box the width you set is the content only, so padding and border make the box bigger. With border-box the width already includes them.

The rule most projects start with
*, *::before, *::after {
  box-sizing: border-box;
}

Put this at the top of the stylesheet. After that, width: 300px always means 300px on screen, whatever you add inside.

margin is different

Margin is never part of the width, in either mode. It is the empty space outside the border that pushes other elements away — and the only layer you can also set to auto to centre a block.

One line to remember

total width = content + (padding × 2) + (border × 2) + (margin × 2)
total height = content + (padding × 2) + (border × 2) + (margin × 2)
